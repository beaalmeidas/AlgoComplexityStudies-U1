# Algorithm Computability and Complexity U1 project
Algorithm Computability and Complexity class unit 1 project.<br/>
Implementing functions to analyze their Big O.
<br/>
<br/>

---

## How to run
1. Clone the repository
```
https://github.com/beaalmeidas/AlgoComplexityStudies-U1.git
```
<br/>

1. Open the folder and run the ```program.exe``` file.
<br/>
<br/>

1. If you want to guarantee the program is updated, recompile before running ```program.exe``` using the following command in a terminal located in the project directory:
```
gcc main.c functions.c utils.c -o program.exe
```
